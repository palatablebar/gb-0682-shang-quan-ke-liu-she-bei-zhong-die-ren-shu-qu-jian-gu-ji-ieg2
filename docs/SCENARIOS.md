# 场景与反例

12小时观测，每小时三处设备、三组两两重叠记录。首小时A120、B110、C90，交集40、30、20，可行联合人数230至250。A100、B80、交集30时联合人数150。A、B、C都100但AB80、AC80、BC0，无可行三方交集，必须隔离。脏样例含缺测、同版冲突、BOM、短行、重复与中文换行。

## 共享平台双商场

`malls.csv` 为共享采集平台混合流：M1、M2 两场复用标签A、B、C，各三小时。M1 首小时 A100、B80、C60，交集30、20、10，联合人数180至190；M2 首小时 A200、B150、C120，交集60、40、30，联合人数340至370。同标签不跨场合并，两场各自成区间。文件中 `M1|M2` 跨场交集记录整行隔离（CROSS_MALL），不进入正式区间。`malls-m2.csv` 为 M2 补传：M2 首小时变为 A210，联合人数350至380，正式版本升至V2；M1 未在补传中出现，保持原版本不变。同批重跑不新增版本。
